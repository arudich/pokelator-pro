## Goal and retained direction

A fast, static Pokémon Champions matchup calculator with keyboard-first controls, plain numeric inputs, percentage damage, and reliable Champions roster/art sources. Keep the current framework-free implementation. Team Builder is enabled, with live Speed and Offense investment comparisons and an account-free named-team library.

**Guiding principle: We know everything about our own team.** Our selected investments, nature, item and other set details are fixed inputs. Hypothetical spreads and nature thresholds model uncertainty about the opponent; never silently change our build to produce a comparison.

## Review findings and decisions

The initial implementation's calculations were placeholders despite stronger claims in the old state note. Review found level-100 math, missing level scaling, incorrect nature/stat formulas, discarded type immunities, averaged Def/SpD, fabricated damage/spread/item modifiers, off-roster fallback species, and uncalled network-loading code. Its only test checked strings in a Markdown document. Keyboard search was missing and storage reads could crash startup. Fixed-height cards overlapped in the rendered browser.

The old 65-total/20-per-stat model and EV/4 investment conversion were rejected. Champions uses **66 total SP, at most 32 per stat**, added to uninvested level-50 stats before nature. The source's `baseStats` values are already uninvested level-50 stats. See [DATA-SOURCES.md](DATA-SOURCES.md) for evidence, provenance, assumptions, and refresh instructions.

The old screenshot ranges were preserved: all eight independently reproduce using fully specified sets and the maintained engine. Jolly's stat label and the roll count in the old note were wrong. The original screenshot is unavailable; its provenance remains unverified. The unchanged old note is [GOLDEN-VALUES-LEGACY.md](GOLDEN-VALUES-LEGACY.md); corrected fixtures are [GOLDEN-VALUES.md](GOLDEN-VALUES.md).

## Usage data update

On November 16, current reference data was downloaded from 524 per-species/format CSVs and reduced to move/item/ability/nature frequencies and the 5,240 reported stat-spread records in the app snapshot. Format selection controls both frequencies and damage rules. Form usage may refer to the source’s parent species, identified in the reference line. Item descriptions come from Pokémon Showdown’s MIT-licensed text; sprites and usage come from Champions Battle Data with visible attribution. See DATA-SOURCES.md for refresh instructions and assumptions.

## Usage-based spread scenarios

Incoming damage now evaluates each reported six-stat spread independently instead of treating maximum investment as the only scenario. Source frequencies describe all sets, not the probability of that spread conditional on a listed move. Only the source’s reported top spreads are included; missing coverage remains unknown. A separate maximum-offense comparison is retained and used to identify the pinned strongest move. Our own build and the sparse opponent identity are never rewritten.

## Ability handling correction

The engine restores a species default when cloning a Pokémon with an empty ability string. Suppressing an ability therefore uses a nonempty no-effect `No Ability` sentinel inside the engine adapter. Do not replace it with an empty string: that silently re-enables Levitate, Sand Force and other defaults. This is covered by damage-output regressions. Icons represent ability assumptions, not forced activation conditions; selected weather remains authoritative, and entry weather, fainted allies, status and unexposed stages are not inferred. Swift Swim, Chlorophyll, Sand Rush, Slush Rush and Surge Surfer use the selected weather/terrain in Speed comparisons; other conditional Speed effects remain future work.

## Usage-based nature defaults

Both nature flags now default to automatic mode. Frequencies of natures that raise the same stat are added together (e.g. Bold + Impish + Relaxed for Defense). The boost is applied per move only when that stat reaches 50% reported usage; Speed-boosting and neutral natures do not imply an offensive boost. Umbreon Singles has 84.5% Defense-boost share; Sylveon SpA changes from 43% in Singles to 95% in Doubles. The checkbox is indeterminate for mixed per-stat defaults. User overrides survive format changes, switching and reload, and existing saved manual flags can be returned to automatic mode with “Use usage defaults”. No actual opponent nature, spread or own-team change is written by these defaults.

The generator now retains `usage[format].rank` from `column_position` in the same downloaded per-Pokémon CSVs used by the roster snapshot. ## Move trial and Offense controls — November 17, 2026

Offense now labels the last group Uh Oh and the first Nearly Guaranteed OHKO, with a soft-blue superscript question mark after OHKO explaining that reported usage spreads do not represent maximum possible bulk. Weather/Terrain controls at the top share the Battle View field state.

A checkbox previews “Try {move} over {move}” without changing the saved team. The optimizer exhaustively checks single-slot swaps from the selected species’ damaging movepool against the currently displayed opponents. Tier points are 5/4/2.5/0.5/0; the highest positive total gain wins, with stable first-found tie breaking. Per-move/per-opponent caching avoids repeating engine work, and search yields between candidates and cancels when its context changes. No positive improvement leaves the checkbox disabled. Changing builds, assumptions, cutoff or fields resets the trial. Previewing never writes team moves or library records.
